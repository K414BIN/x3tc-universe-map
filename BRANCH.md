# Ветка `story` — сюжетное наложение

Ответвлена от `main`. Здесь строится сюжетная модель поверх базовой карты.

## Цель

- квестовые линии X3:TC и последовательность перемещений по секторам;
- ключевые сектора: где выдаются квесты, где происходят ключевые события;
- требования и блокировки: рейтинг, предыдущие квесты, фракции;
- оптимальный порядок прохождения с учётом географии (врата, расстояния).

## Источники

- базовая карта (`data/universe.json`): сектора, врата, расы;
- сюжетные данные из игры (скрипты `x3story` в сохранении) и мануал;
- `x3tc.net/x3_tc_info/` — база знаний по сюжету.
