# Ветка `trade` — торговое наложение

Ответвлена от `main`. Здесь строится торговая модель поверх базовой карты.

## Цель

Показать, где какой товар покупают и где продают:

- для каждого товара — список секторов, где он **продаётся** (производится или
  есть в ассортименте торговой станции) и где **покупается** (потребляется
  фабриками);
- цены (мин/макс) и направления торговли;
- производственные цепочки: сырьё → промежуточный продукт → готовый товар.

## Источники

- `x3tc.net/x3_tc_map/factory.php?c=CODE` — страница экземпляра станции:
  сектор, тип, владелец, список продаваемых товаров с ценами.
- `x3tc.net/x3_tc_factories/factory.php?c=TYPE` — страница типа фабрики:
  продукция + ресурсы (что фабрика покупает), время цикла, цены.
