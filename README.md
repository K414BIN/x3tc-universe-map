# X3TC Universe Map

Офлайн-карта вселенной **X3: Terran Conflict**: 231 сектор, 1699 станций,
3117 астероидов, 514 переходов (врата). Данные сняты с
[x3tc.net/x3_tc_map](https://x3tc.net/x3_tc_map/) 2026-11-07.

## Страница

`index.html` — самодостаточная интерактивная карта (данные вшиты внутрь,
интернет не нужен): сетка 24×20, цвет сектора по расе, поиск по названию,
клик по сектору → врата, станции, астероиды.

## Ветки

| Ветка | Назначение |
|---|---|
| `main` | базовая карта вселенной (эта страница) |
| `trade` | торговое наложение: где какой товар покупают и продают |
| `military` | военное наложение: флоты, угрозы, оборона |
| `story` | сюжетное наложение: квестовые линии и перемещения по сюжету |

Ветки `trade`, `military`, `story` ответвлены от `main`; каждая содержит
свою версию `index.html` и свои CSV/JSON поверх базовых данных.

## Структура

```
index.html          — интекративная карта (всё в одном файле)
data/
  universe.json     — полные данные: сектора, врата, станции, астероиды
  grid.json         — координаты ячеек на карте
  sectors.csv       — сектора (id, координаты, раса, статус, врата)
  stations.csv      — станции (сектор, имя, раса)
  asteroids.csv     — астероиды (сектор, ресурс, содержание, координаты)
  gates.csv         — переходы (откуда → куда)
  codes.txt         — коды секторов (base64 → id)
tools/
  fetch_sectors.sh  — скачать страницы секторов с x3tc.net
  parse_sectors.py  — HTML → data/universe.json
  gen_map.py        — data/* → index.html + CSV
docs/DATA_SOURCE.md — описание источника и полей
```

## Обновление данных

```bash
bash tools/fetch_sectors.sh   # качает sectors/*.html (231 файл)
python3 tools/parse_sectors.py # собирает data/universe.json
python3 tools/gen_map.py       # пересобирает index.html и CSV
```

## Важно

Это **ванильная** вселенная X3:TC. У конкретной установки игры набор станций
может отличаться — для стратегии сверяйтесь с файлом сохранения.

## Источник

Данные: [x3tc.net/x3_tc_map](https://x3tc.net/x3_tc_map/) (коды секторов —
base64 от числового ID, например `MjI1NDEzMQ` → `2254131`).
