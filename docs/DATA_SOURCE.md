# X3:TC — карта вселенной (offline)

Локальная копия карты вселенной X3: Terran Conflict с сайта
<https://x3tc.net/x3_tc_map/> (русская версия <https://ru.x3tc.net/x3_tc_map/>
не содержит данных — это заглушка).

Снято 2026-11-07.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Интерактивная офлайн-карта: сетка 24×20, ячейки 80×80, цвета по расе (Ксенон — красный), поиск, клик по сектору → врата/станции/астероиды |
| `universe.json` | Полные данные по всем секторам (id, имя, координаты, раса, статус, врата, станции, астероиды) |
| `sectors.csv` | Сектора: id, code, имя, x, y, раса, статус, планеты, счётчики, 4 врата |
| `stations.csv` | 1699 станций: сектор + имя + раса + code |
| `asteroids.csv` | 3117 астероидов: сектор + ресурс + содержание + координаты |
| `gates.csv` | 514 переходов: откуда → куда |
| `sectors/` | Сырые HTML-страницы секторов (по одному на сектор) |
| `codes.txt` | Коды секторов (`c=` из ссылки) |
| `grid.json` | Координаты ячеек с карты |
| `fetch_sectors.sh` | Скрипт скачивания страниц секторов |
| `parse_sectors.py` | Парсер HTML → `universe.json` |
| `gen_map.py` | Генератор `X3TC_map.html` + CSV |

## Данные

- Секторов: 231 (сетка 24 × 20, координаты 0..23 по X, 0..19 по Y)
- Станций: 1699
- Астероидов: 3117
- Переходов (врата): 514 (из них 2 односторонние: Меж миров ↔ Священная реликвия)
- Расы: Аргон 33, Сплит 31, Телади 30, Земляне 30, Борон 27, Паранид 27,
  Пират 20, без расы 15 (в т.ч. 13 «Неизвестный сектор»), Ксенон 11, Хаак 3, Яки 3, Гонер 1

Код сектора в ссылке (`c=...`) — это base64 от числового ID сектора
например `MjI1NDEzMQ` → `2254131`.

## Важно

Это **ванильная** вселенная X3:TC. У данной установки игры набор станций
нестандартный (см. заметки по проекту) — для стратегии сверяйтесь с
сохранением игры, а не только с этой картой.

## Обновление

```bash
bash fetch_sectors.sh      # докачать/обновить страницы секторов
python3 parse_sectors.py   # пересобрать universe.json
python3 gen_map.py         # пересобрать X3TC_map.html и CSV
```
